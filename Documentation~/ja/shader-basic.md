## 基本(色・立体感)

地の色と凹凸です。

| 項目 | 説明 |
|---|---|
| メインテクスチャ | 地の色のテクスチャ。A は「切り抜き」「半透明」のときの透明度に使います |
| メインカラー | テクスチャに掛ける色。A は透明度です |
| 立体感 (ノーマルマップ) | 凹凸の向きを表すテクスチャ。陰影・ハイライト・リムが凹凸に合わせて変わります |
| 立体感の強さ | ノーマルマップの効きの強さ(0〜2) |
| 立体感 2枚目 (細かい凹凸) | 1枚目に重ねる、細かい凹凸のノーマルマップ。タイリングで細かく繰り返せます |
| 立体感 2枚目の強さ | 2枚目の効きの強さ(0〜2) |
| くぼみ (AO マップ) | くぼみや重なりの暗さ。暗い所ほど影になりやすくなります |
| くぼみの強さ | AO マップの効きの強さ |

> ノーマルマップが無い場合は、**Tools > GalaxyToon > ノーマルマップを作る** で、メインテクスチャから作れます。

## 色調補正

テクスチャを描き直さずに、色味を変えます。どれかを初期値から変えると有効になります。

| 項目 | 説明 |
|---|---|
| 色相のずらし | 色相を回します(-0.5〜0.5。±0.5 で反対色) |
| 彩度 | 0 で白黒、1 でそのまま、2 で鮮やか |
| 明るさ | 0 で黒、1 でそのまま |
| ガンマ | 中間の明るさを変えます。1 でそのまま |

## 金属・つや・映り込み

URP 標準の「Metallic」「Smoothness」と同じ意味の値です。金属かつやを 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| 金属 | 0=金属でない、1=金属。金属ほど地の色が暗くなり、映り込みが地の色に染まります |
| つや | 0=ざらざら、1=つるつる。つやがあるほど、小さく鋭いハイライトと映り込みが出ます |
| 金属・つやマップ | R=金属、A=つや(URP 標準と同じ並び) |
| 映り込みの強さ | 反射プローブの映り込みの強さ |
| 映り込みの段数 | 映り込みを何段階に塗り分けるか。0 でなめらか、増やすほどトゥーンらしくなります |

## トライプラナー

UV の無いモデル(建物・岩など)や、UV が伸びてしまうモデルに、ワールドの3方向からテクスチャを貼ります。

| 項目 | 説明 |
|---|---|
| トライプラナー | ON にすると、メインテクスチャを UV ではなくワールド座標で貼ります |
| トライプラナーの細かさ | 1m あたりに何回繰り返すか |
| トライプラナーの境目のくっきりさ | 3方向の境目の混ざり方。大きいほど境目がくっきりします |

## ライト

どの光で照らすかと、明るさの範囲を決めます。

| 項目 | 説明 |
|---|---|
| 主光源 | **CharacterLight**: `GalaxyToonLight` のキャラ専用ライト(置いていなければシーンのメインライト)<br>**SceneMainLight**: シーンのメインライト<br>**BakedLightAndShadowOnly**: ライトマップの光と、落ちる影だけを使います(焼き込んだ背景用) |
| 明るさの下限 | これより暗くしません。暗い場面で真っ黒になるのを防ぎます |
| 明るさの上限 | これより明るくしません。白飛びを防ぎます |
| ライトの色を無視 | 1 にすると、ライトの色を白黒にして明るさだけ使います |
| 環境光の強さ | シーンの環境光(Skybox / Ambient)を足す量 |
| 追加ライトの強さ | ポイントライト・スポットライトを足す量。0 なら追加ライトの計算をしません |
| 焼いた光の段数 | ライトマップの光を何段階に塗り分けるか。0 でなめらか |

- 影(落ち影)は、主光源の設定に関係なく、シーンのメインライトのシャドウマップから読みます。
- 追加ライトは、当たる/当たらないを「影1の境界」で切るので、トゥーンらしい光になります。

## 影

光の当たり具合を、最大3段の影に塗り分けます。

### 段影

| 項目 | 説明 |
|---|---|
| 影1の色 | 1段目の影の色。A が濃さです |
| 影1の境界 | どこから影になるか。大きいほど影が広くなります |
| 影1のぼかし | 境界のぼかし幅。0 でくっきり |
| 影2の色・境界・ぼかし | 2段目の影。色の A を 0 より大きくすると有効になります |
| 影3の色・境界・ぼかし | 3段目の影。色の A を 0 より大きくすると有効になります |
| 影の濃さマスク | R が暗い所ほど影が薄くなります。影を付けたくない部分を塗ります |
| ほかの物の影を受ける | ほかの物(や自分)が落とす影を、どれだけ受けるか |
| 境界のアンチエイリアス | 影の境界のギザギザを抑えます |

### ランプ

影の色をグラデーション画像で決める方法です。テクスチャを入れると、段影の代わりにランプが使われます。

| 項目 | 説明 |
|---|---|
| 影のランプ | 左=いちばん暗い、右=光が当たる所 のグラデーション画像 |
| ランプの段数 | 画像に、部位ごとのグラデーションを縦に何段並べたか |
| ランプの段 | 部位IDマップが無いとき、何段目を使うか(0=いちばん上) |
| 部位IDマップ | R の値で、ピクセルごとに使う段を選びます(0=いちばん上 … 1=いちばん下) |

> ランプのひな形は **Tools > GalaxyToon > ランプのひな形を作る** で作れます(上から 肌 / 髪 / 服 / 金属 の4段)。画像編集ソフトで描き直して使えます。

## アニメ塗り

日本のアニメ調に塗ります。**アニメ塗り** を ON にすると有効になり、OFF のときは今までと同じ見た目です。

| 項目 | 説明 |
|---|---|
| アニメ塗り | ON / OFF |
| 影の境界をくっきり | セル塗りのように、影の境界を細くします |
| 影色の色相ずらし | 影色の色相を回します。- で青紫、+ で赤みの影 |
| 影色の鮮やかさ | 地の色から自動で作る影色の鮮やかさ |
| 影色の明るさ | 影色の明るさ。小さいほど暗い影 |
| 影の境界の色 | 影の境界に入れる細い帯の色(肌の赤い境界線など)。A が強さです |
| 影の境界の色の幅 | 境界の帯の幅 |
| ライトで色をくすませない | ライトの明るさのムラで、塗った色が濁らないようにします |
| 細かい凹凸を消す | ノーマルマップを弱め、面をベタ塗りにします |
| テクスチャの細かい模様を消す | テクスチャの汚れやムラをならして、色面にします |
| 模様を消す強さ | 模様をならすぼかしの強さ(ミップの段) |
| 写実的なつや・映り込みを消す | 金属・つや・映り込みの写実的な表現を消します |

輪郭線を画面上で同じ太さにする設定は、[輪郭線](shader-outline-dissolve.md#輪郭線) にあります。
