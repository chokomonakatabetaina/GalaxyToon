## 輪郭線

裏面を法線の向きへ押し出して描く方式です。描画モードが **半透明** のときは描きません。

| 項目 | 説明 |
|---|---|
| 輪郭線の太さ | 太さ(cm)。0 にすると、輪郭線の描画そのものが止まります |
| 輪郭線になめらか法線を使う | ツールで焼いたなめらか法線を使います。角で線が割れたり途切れたりしません |
| 輪郭線の色 | 線の色 |
| 輪郭線にテクスチャ色を混ぜる | 線の色に地の色を混ぜる量 |
| 輪郭線をライトの明るさに合わせる | 暗い場面で線だけが浮かないよう、主光源の明るさに合わせます |
| 近いと細くする | カメラが 1m より近いとき、線を細くする量 |
| 輪郭線を画面上で同じ太さに | 1 にすると、遠くても線が細くなりません(アニメの線) |
| 輪郭線の太さマスク | R で、場所ごとに太さを変えます(黒=線なし) |

### なめらか法線の焼き方

モデルの角(UV の継ぎ目や硬いエッジ)では、輪郭線が割れることがあります。次の手順で直せます。

1. プレハブか、シーン上のキャラを選びます。
2. **Tools > GalaxyToon > 輪郭線用のなめらか法線を焼く** を実行します。
3. 「輪郭線になめらか法線を使う」が ON になっていることを確認します(初期値は ON)。

焼いたメッシュは `OutlineNormals/` フォルダに保存され、Renderer に差し替えられます。元の FBX は変わりません。

## ディゾルブ

消える・現れる演出です。**ディゾルブを使う** を ON にすると有効になります。ディゾルブで消した所は、影・深度・輪郭線でも同じように消えます。

| 項目 | 説明 |
|---|---|
| ディゾルブを使う | ON / OFF |
| ディゾルブの量 | 0=そのまま、1=消える |
| ディゾルブの方式 | **Noise**: ノイズの模様で、ばらばらに消えます<br>**Position**: 決めた向きに沿って、端から順に消えます |
| 位置: 消えていく向き | XYZ=消えていく向き(ワールド)、W=消える範囲(m) |
| 位置: 開始位置 | 物体の原点からの距離(m)。上から消すなら、向きを (0, -1, 0)、開始を「-身長」にします |
| ノイズテクスチャ | R をノイズとして使います。無い場合は、シェーダー内のノイズを使います |
| ノイズの細かさ | ノイズの細かさ |
| ノイズの強さ | 境目のギザギザの強さ。2 以上にすると、ノイズテクスチャを使います |
| 逆にする | 消える代わりに現れます(服の入れ替えの新しい服など) |
| 位置: ワールドの高さで測る | 体の全部品で同じ高さの線になります(転送の演出用) |
| 境目の幅 | 光る境目の幅 |
| 境目の色 | 境目の色(HDR)。A が強さです |

> **GalaxyTeleport** コンポーネントを使うと、光る線が体を走る転送・着替えの演出を自動で再生できます。ビルドでは、ディゾルブを ON にしたマテリアルが1つ以上含まれている必要があります。

## カメラが近いと透ける

カメラが近づいたとき、網目(ディザ)で透かして消します。寄りのカメラで髪や体にめり込んだとき、中が見えないようにする機能です。不透明のまま透けるので、描画順は変わりません。

| 項目 | 説明 |
|---|---|
| カメラが近いと透ける | ON / OFF |
| 透け: これより近いと消える | この距離より近いと完全に消えます(m) |
| 透け: これより遠いと消えない | この距離より遠いと透けません(m) |
