「〜を影の側では消す」という項目は、影の中ではその光を弱める量です(0=影でも光る、1=影では消える)。

## ハイライト・マットキャップ

### ハイライト

段のついた光沢です。髪・瞳・金属などに使います。色の A を 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| ハイライトの色 | 色。A が強さです |
| ハイライトの大きさ | 光る範囲の大きさ |
| ハイライトのぼかし | 縁のぼかし。0 でくっきり |
| ハイライトのランプ | 左=光の外側、右=光の中心 のグラデーション画像。光の形(段・縞)と色を絵で決められます。段は影のランプと共通です |

### マットキャップ

視線から見た法線の向きで、球のテクスチャを貼ります。金属や光沢の表現に使います。

| 項目 | 説明 |
|---|---|
| マットキャップ | 球のテクスチャ。テクスチャを入れ、色の A を 0 より大きくすると有効になります |
| マットキャップの色 | 掛ける色。A が強さです |
| マットキャップを影の側では消す | 影の中で弱める量 |
| マットキャップ 2枚目 | 2枚目の球テクスチャ |
| マットキャップ 2枚目の色 | 掛ける色。A が強さです |
| マットキャップ 2枚目の合成 | Add=足す、Multiply=掛ける |
| マットキャップ 2枚目のマスク | R が白い所だけに出します |
| マットキャップ 2枚目を影の側では消す | 影の中で弱める量 |

## 異方性ハイライト(髪の天使の輪)

髪の流れに沿った、細長い光です。色の A を 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| 異方性ハイライトの色 | 色。A が強さです |
| 異方性ハイライトの向き | 髪の流れの向き。Tangent=接線、Bitangent=従法線。輪が縦に出るときは、もう一方に切り替えます |
| 異方性ハイライトの位置ずらし | 輪の位置を上下にずらします |
| 異方性ハイライトの細さ | 大きいほど細く鋭い輪になります |
| 異方性ハイライトの境界 | 光る範囲 |
| 異方性ハイライトのぼかし | 縁のぼかし |
| 異方性ハイライトを影の側では消す | 影の中で弱める量 |
| 天使の輪もハイライトのランプで形を決める | ON にすると、輪の形と色を「ハイライトのランプ」で決めます |
| 濡れ髪 | 濡れたとき、毛が束になり、束の間が暗くなり、天使の輪が細く鋭くなります。量は「濡れ」の値です |
| 濡れ髪 束の細かさ | 束の数(UV 1 あたり) |

## 逆光ライト

光がキャラの後ろ(カメラの反対側)にあるとき、縁が光ります。色の A を 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| 逆光ライトの色 | 色。A が強さです |
| 逆光ライトの境界 | 光る範囲 |
| 逆光ライトのぼかし | 縁のぼかし |
| 逆光ライトの指向性 | 大きいほど、光が真後ろにあるときだけ光ります |
| 逆光ライトの視線の影響 | 見る角度の影響。1 でカメラから見た縁だけが光ります |
| 逆光ライトにテクスチャ色を混ぜる | 光の色に地の色を混ぜる量 |

## リムライト

輪郭の内側の縁を光らせます。色の A を 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| リムライトの色 | 色。A が強さです |
| リムの境界 | 光る範囲 |
| リムのぼかし | 縁のぼかし |
| リムの細さ | 大きいほど細い縁になります |
| リムを影の側では消す | 影の中で弱める量 |
| 深度リム | ON にすると、深度テクスチャを使って、シルエットの縁だけを光らせます(体の内側の凹凸では光りません) |
| 深度リムの幅 | 光る幅(cm) |
| 深度リムの奥行きしきい値 | 後ろの物とこれ以上離れていたら縁とみなします(m) |

> 深度リムを使うには、URP Asset の **Depth Texture** を ON にしてください。

## ラメ・屈折

### ラメ

細かい鏡の粒が、光と視線の向きでキラキラまたたきます。色の A を 0 より大きくすると有効になります。

| 項目 | 説明 |
|---|---|
| ラメの色 | 色。A が強さです |
| ラメの出る所 | R が白い所にだけ出します |
| ラメの細かさ | UV 1 あたりの粒の数 |
| ラメの粒の大きさ | 粒の大きさ |
| ラメの量 | 粒の多さ |
| ラメの光る角度の鋭さ | 大きいほど、一瞬だけ光ります |
| ラメを影の側では消す | 影の中で弱める量 |

### 屈折

描画モードが **半透明** のときだけ使えます。後ろの景色を法線でずらして、ゆがんで見せます。

| 項目 | 説明 |
|---|---|
| 屈折 | ゆがみの強さ。0 なら使いません |
| 屈折の虹色のにじみ | RGB をずらして、虹色ににじませる量 |

> 屈折を使うには、URP Asset の **Opaque Texture** を ON にしてください。

## 発光

ライトに関係なく光らせます。発光色を黒以外にすると有効になります。発光は2枚まで重ねられます。

| 項目 | 説明 |
|---|---|
| 発光マスク | 光る所(白=光る) |
| 発光色 | 光る色(HDR)。明るくするとブルームで光って見えます |
| 発光 自動スクロール | ON で、下の「動き」に合わせてマスクが動きます |
| 発光 動き | XY=1秒あたりのスクロール量、Z=回転角(°)、W=1秒あたりの回転(°) |
| 発光 明滅 | 1秒あたりの明滅の回数。0 なら明滅しません |
| 発光レイヤー2 マスク / 色 / 自動スクロール / 動き / 明滅 | 2枚目の発光。項目の意味は1枚目と同じです |

## レイヤー 1〜3

メインテクスチャの上に、模様・柄・光の帯などを最大3枚重ねます。テクスチャを入れると有効になります。

| 項目 | 説明 |
|---|---|
| レイヤー マスク | R が白い所にだけ重ねます |
| レイヤー テクスチャ | 重ねるテクスチャ。タイリング・オフセットも使えます |
| レイヤー 色 | 掛ける色。A が濃さです |
| レイヤー 合成 | Normal=上に重ねる、Add=足す、Screen=スクリーン、Multiply=掛ける |
| レイヤー 自動スクロール | ON で、下の「動き」に合わせて動きます |
| レイヤー 動き | XY=1秒あたりのスクロール量、Z=回転角(°)、W=1秒あたりの回転(°) |
| レイヤー フェード | 0=消える、1=出る。スクリプトから動かして、出し入れに使えます |
| レイヤー 明滅 | 1秒あたりの明滅の回数。0 なら明滅しません |
| レイヤー 明滅のずれ | 明滅のタイミングをずらします。複数のレイヤーを交互に光らせるときに使います |
| レイヤー 光る | 1 にすると影やライトを受けず、発光として足します(Multiply は光りません) |
