# シェーダー: ファー

[ドキュメント目次](README.md)

`GalaxyShader/ToonFur` は、毛並みを描くシェーダーです。同じメッシュを法線の向きへ少しずつ浮かせて何層も重ね、層ごとに毛の断面を切り抜きます(シェル法)。

このシェーダーは、マテリアルに設定するだけでは描かれません。**GalaxyToonFur** コンポーネントから描きます。

---

## 使い方

1. **GalaxyShader/ToonFur** のマテリアルを作ります。
2. 毛を生やしたい Renderer(MeshRenderer か SkinnedMeshRenderer)に **GalaxyToonFur** を付けます。
3. `furMaterial` に、1 で作ったマテリアルを入れます。

スキンメッシュは毎フレーム形を取り直すので、アニメーションしても毛がついてきます。体が動くと、毛先がなびきます。

## マテリアルの項目

| 項目 | 説明 |
|---|---|
| 毛の色 (テクスチャ) | 毛の色のテクスチャ |
| 毛の色 | テクスチャに掛ける色 |
| テクスチャの透明部分を切る | テクスチャの A がこれより小さい所は描きません |
| 毛の生える所 | R が白い所に毛が生えます |
| 毛の長さ | 毛の長さ(cm) |
| 毛の密度 | UV 1 あたりの毛の本数 |
| 毛の太さ | 毛の太さ。上の層ほど細くなります |
| 重力で垂れる | 毛先が重力で垂れる量 |
| 根元の暗さ | 根元を暗くする量(毛の重なりの影) |
| 毛先の色 | 毛先に混ぜる色。A が混ぜる強さです |
| 影の色 | 影の色 |
| 影の境界 | どこから影になるか |
| 影のぼかし | 影の境界のぼかし |
| 毛先の縁の光 | 毛先の縁の光(HDR)。A が強さです |
| 明るさの下限 / 上限 | `GalaxyShader/Toon` の同名の項目と同じです |

ライトは `GalaxyShader/Toon` と同じく、`GalaxyToonLight` のキャラ専用ライト、なければシーンのメインライトを使います。

## コンポーネントの項目(GalaxyToonFur)

| 項目 | 説明 |
|---|---|
| furMaterial | ファーのマテリアル。空なら描きません |
| shells | 層の数(2〜32)。多いほどふわふわですが、重くなります。8〜16 が目安です |
| subMesh | 毛を生やすサブメッシュの番号。-1 で全部 |
| sway | 体が動いたとき、毛がなびく強さ |
| stiffness | なびきが戻る速さ |

> 層の数だけ描画が増えます。広い面や、たくさんのキャラに使うときは、層の数を減らしてください。
