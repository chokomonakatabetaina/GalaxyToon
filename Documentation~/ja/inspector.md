# Inspector の使い方

[ドキュメント目次](README.md)

`GalaxyShader/Toon` のマテリアルを選ぶと、GalaxyToon 専用の Inspector が表示されます。

---

## 画面の並び

上から順に、次のように並んでいます。

1. 表示言語・ロゴ
2. シェーダー ON/OFF ボタン
3. 描画モード・描画する面・描画順のずらし
4. プリセット
5. テクスチャの見比べ
6. 検索・開閉・初期化のボタン
7. 機能ごとの見出し(折りたためます)
8. Render Queue
9. 表示の設定

---

## 表示言語

左上のドロップダウンで **日本語 / English** を切り替えます。

- 選んだ言語は、PC ごとに記録されます(EditorPrefs)。
- 言語を変えても、見出しの開閉やマテリアルの値は変わりません。

## シェーダー ON/OFF

**「シェーダー ON — 押すと OFF」** ボタンを押すと、GalaxyToon を使う**全マテリアル**が、同じテクスチャのまま URP 標準の Lit で描かれます。トゥーンにした効果を見比べるための機能です。

- マテリアルの値は変わりません。
- OFF の間は輪郭線も消えます。
- ショートカットは **Ctrl+Shift+T** です(メニュー **Tools > GalaxyToon > シェーダー OFF**)。

## 描画モード

| 描画モード | 使う所 | 動作 |
|---|---|---|
| 不透明 | ふつうの面 | 深度を書き、影を落とし、輪郭線を描きます |
| 切り抜き | 髪の毛先・レース・網 | テクスチャの A が「切り抜きのしきい値」より小さい所を描きません |
| 半透明 | ガラス・頬染め・涙 | 後ろが透けて重なります。輪郭線・影を落とす処理・深度は止まります |

描画モードを選ぶと、ブレンド・ZWrite・描画順(Render Queue)・使うパスが自動で設定されます。

## 描画する面

| 選択肢 | 使う所 |
|---|---|
| 両面 | 髪・スカート・薄い布 |
| 表だけ | ふつうのモデル(いちばん軽い) |
| 裏だけ | 内側から見る球などの特殊な用途 |

## 描画順のずらし

同じ面に重ねた文字・デカール・ステッカーは **+1** にします。下の面より後に描かれるので、重なって消えなくなります。範囲は -5〜+5 です。

---

## プリセット

部位や素材の名前のボタンを押すと、それに合った値がまとめて入ります。**テクスチャ・メインカラー・描画モードは変わりません**(「涙・しずく」など、半透明が前提のものは描画モードも変わります)。

| 行 | 内容 |
|---|---|
| キャラ | 肌・顔・髪などの部位の基本設定。影・リム・輪郭線などの値を入れます |
| 背景 | 建物・小物向け。シーンのライト・環境光・影を受け、輪郭線は付けません |
| 肌・服の質感 | 汗・濡れ・布・ラテックス・革などの質感だけを上書きします |
| 追加 (今の設定に足す) | ほかの値は変えずに、汗・液体・汚れ・演出だけを足します。重ねて押せます |
| キャラの仕上げ | 髪の影・瞳・ラメ・近づくと透けるなど、見栄えを上げる機能を足します |

**基本以外リセット** を押すと、テクスチャ・メインカラー・立体感・描画モード・描画する面は残し、ほかの項目を全部初期値に戻します。

各プリセットの内容は [プリセット一覧](presets.md) にあります。

---

## テクスチャの見比べ

各テクスチャの右にある **オフ** を押すと、テクスチャを選び直さずに一時的に外せます。もう一度 **戻す** を押すと元に戻ります。

- 外している間も、テクスチャの参照はマテリアルに残っています。
- **全部オフ** / **全部戻す** で、全テクスチャをまとめて切り替えられます。

## 検索

検索欄に文字を入れると、名前に含まれる項目だけが見出しごとに表示されます。

- 空白で区切ると、すべての語を含む項目だけが表示されます。
- 項目名(日本語・英語)、内部名(`_ShadowColor` など)、見出し名のどれでも探せます。
- 大文字・小文字は区別しません。

## 開閉と初期化

| ボタン | 動作 |
|---|---|
| 1つずつ開く | ON のとき、見出しを開くとほかの見出しが自動で閉じます(アコーディオン) |
| 全部開く / 全部閉じる | 全見出しを開く / 閉じる |
| 全て初期化 | テクスチャ・描画モードも含めて、全項目をシェーダーの初期値に戻します(確認あり) |
| この項目を初期化 | 各見出しの右上にあります。その見出しの項目だけを初期値に戻します(確認あり) |

見出しの開閉状態は記録されます。

## 使用中の表示

- 機能が効いている見出しには **「● 使用中」** が付き、背景に色が付きます。
- 初期値から変えた項目は、入力欄に色が付きます。

色は、いちばん下の **表示の設定** で変えられます。**色を初期値に戻す** で元の色に戻ります。

---

## 機能の自動 ON/OFF

GalaxyToon は、使っていない機能をシェーダーから外して、計算もビルドもしないようにしています。この ON/OFF は Inspector が自動で行います。

| 機能が ON になる条件 | 例 |
|---|---|
| テクスチャを入れる | 立体感(ノーマルマップ)、影のランプ、レイヤー、金属・つやマップ |
| 色の A(強さ)を 0 より大きくする | ハイライト、リム、異方性、逆光、ラメ、影2・影3 |
| 値を 0 より大きくする | 顔の陰影を平らに、金属・つや、追加ライト、髪の影を受ける |
| トグルを ON にする | 濡れ・汗・液体、ディゾルブ、深度リム、SDF 顔影、瞳、トライプラナー、アニメ塗り |

輪郭線は、太さを 0 にすると描画そのものが止まります。

スクリプトでマテリアルの値を変えた場合は、キーワードが自動では切り替わりません。[エディタツール](editor-tools.md) の **全マテリアルの機能を整理** を実行すると、全マテリアルのキーワードを値に合わせて直せます。
