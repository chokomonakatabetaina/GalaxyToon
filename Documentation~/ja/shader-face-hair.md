## 顔

鼻や頬の細かい影を消し、アニメらしい、すっきりした顔の陰影にします。

| 項目 | 説明 |
|---|---|
| 顔の陰影を平らに | 法線を顔の正面へ寄せて、細かい影を消します(0〜1) |
| 顔を球として塗る | 頭を球とみなした法線へ寄せて、丸くなめらかな陰影にします(0〜1) |
| SDF 顔影を使う | ON にすると、光の角度に対する影の形を SDF 影マップで決めます |
| SDF 顔影 | SDF 影マップ。R=光が右から、G=光が左から のときの影の境目 |

### 使い方

1. キャラのルートに **GalaxyToonFace** を付けます。頭ボーンの向きが毎フレーム顔のマテリアルに渡り、首を振っても陰影がついてきます。
2. 「顔の陰影を平らに」を 0.8 くらいにします(プリセット **顔** でも入ります)。
3. SDF 顔影を使う場合は、**Tools > GalaxyToon > SDF 影マップを作る** で影マップを作ります。作ったテクスチャは、マテリアルに自動で入ります。

> `GalaxyToonFace` を付けていない場合は、モデルの +Z を顔の正面とみなします。

## 瞳

瞳に、奥行き・ハイライト・うるうる・きらめきを付けます。顔テクスチャの中の瞳にも、別メッシュの瞳にも使えます。

| 項目 | 説明 |
|---|---|
| 瞳の効果を使う | ON / OFF |
| 瞳1の範囲 / 瞳2の範囲 | 瞳がある UV の長方形(XY=左下、ZW=右上)。この長方形に内接する円の中だけに効果が出ます |
| 瞳の奥行き | 見る角度で瞳の模様が奥へずれ、角膜の下にあるように見えます |
| 瞳のハイライトの色 | ハイライトの色。A が強さです |
| 瞳のハイライトの位置 | XY=大きいハイライト、ZW=小さいハイライトの位置(-1〜1。画面の右=+X、上=+Y) |
| 瞳のハイライトの大きさ | ハイライトの大きさ |
| うるうる | ハイライトが小刻みに揺れ、瞳の下に揺れる水面の光が出ます |
| きらめきの色 | 十字の星の色。A が強さで、0 なら出ません |
| きらめきの数 | 星の数 |
| きらめきの速さ | またたく速さ |

- ハイライトは画面を基準に置かれるので、テクスチャ上で瞳が回転・反転していても、同じ向きに出ます。
- 瞳の範囲は、キャラを選んで **Tools > GalaxyToon > 瞳の範囲を探す** を実行すると、自動で入ります。

## 頬染め

頬をほんのり赤くし、照れ線を入れます。

| 項目 | 説明 |
|---|---|
| 頬染め | 量(0〜1)。`GalaxyToonEffects` の `blush` で、ゲーム中に動かせます |
| 頬染めの色 | 色。A が濃さです |
| 頬の位置 | 頬の中心の UV(XY=頬1、ZW=頬2) |
| 頬染めの大きさ | 頬染めの半径(UV) |
| 頬染めのぼかし | 縁のぼかし |
| 照れ線 | 斜めの照れ線を重ねる量 |

頬の位置は、キャラを選んで **Tools > GalaxyToon > 頬の位置を探す** を実行すると、自動で入ります。

## 髪の揺れ

ボーンの無い髪を、シェーダーで揺らします。

| 項目 | 説明 |
|---|---|
| 髪の揺れ | 揺れの強さ(0〜2)。0 なら揺れません |

キャラのルートに **GalaxyToonHairSway** を付けると、首を振る・歩く・止まるのに合わせて、毛先がふわっと遅れてついてきます。根元は動かず、毛先ほど大きく動きます。

## 髪の影

前髪の影を、顔と瞳に落とします。

| 項目 | 使うマテリアル | 説明 |
|---|---|---|
| 髪の影を落とす | 髪 | ON にすると、この髪の形で影を作ります |
| 髪の影を受ける | 顔・瞳 | 影を受ける量。1 にします |
| 髪の影の長さ | 顔・瞳 | 光の向きへ影をずらす量(cm) |
| 髪の影のすき間 | 顔・瞳 | 肌に触れている髪で影が出すぎないよう、すき間をあけます(cm) |

### 使い方

1. **Tools > GalaxyToon > 髪の影を有効にする** を実行して、使っている URP Renderer に **GalaxyHairShadowFeature** を追加します(Renderer の Add Renderer Feature から手で足しても同じです)。
2. 髪のマテリアルにプリセット **髪の影を落とす** を当てます。
3. 顔・瞳のマテリアルにプリセット **髪の影を受ける** を当てます。
4. キャラのルートに **GalaxyToonFace** を付けます。

- 影は、画面上で光の来る向きへ少しずらした所に「自分より手前の髪」があるかで判定します。
- `GalaxyToonFace` が有効なキャラが1人もいない場面では、必要な処理を丸ごと止めます(負荷 0)。

## ステンシル

前髪の上から、瞳や眉を透かして見せます。見出しの中のボタンで設定します。

| ボタン | 使うマテリアル | 動作 |
|---|---|---|
| 書き込む (瞳・眉) | 瞳・眉 | ステンシル 1 を書き込みます。描画順はそのままです |
| 透かす (髪) | 髪 | ステンシル 1 の所は描きません。描画順を瞳の後(Geometry+1)にします |
| 使わない | 全部 | ステンシルを無効に戻します |

ステンシルは、髪のその部分を描かないので、瞳がくっきり見えます。前髪をグラデーションで半透明にしたい場合は、**Tools > GalaxyToon > 前髪を透過する**(`GalaxyToonSeeThroughBangs`)を使います。
