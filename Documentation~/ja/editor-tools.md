## GalaxyToon に移行

ほかのシェーダーのマテリアルを、まとめて `GalaxyShader/Toon` に移します。VRM(VRoid)のキャラなら、選んで実行するだけで、顔・瞳・輪郭線・髪の影の設定まで終わります。

**使い方**

1. ヒエラルキーでキャラを選びます(Project でマテリアルを選んでもかまいません)。
2. **Tools > GalaxyToon > GalaxyToon に移行 (MToon・lilToon・Lit など)** でウィンドウを開きます。
3. 一覧で、移行するマテリアルと部位を確かめます。部位はマテリアル名から自動で選ばれます。違っていたら選び直してください。
4. **移行する** を押します。結果は Console に出ます。

**対応しているシェーダー**

| 元のシェーダー | 写す内容 |
|---|---|
| MToon(VRM 0.x / VRM 1.0) | 色・テクスチャ・影色・影の境界とぼかし・ノーマル・発光・マットキャップ・リム・輪郭線(太さ・色・マスク)・描画モード・両面 |
| lilToon | 色・テクスチャ・影1〜3(色・境界・ぼかし・マスク)・リム・マットキャップ・発光・輪郭線・描画モード・描画する面 |
| UTS(Unity-Chan Toon Shader) | 色・テクスチャ・1影・2影(色・境界・ぼかし)・ノーマル・リム・マットキャップ・発光・輪郭線・描画モード |
| URP Lit / Simple Lit / Unlit、Standard | 色・テクスチャ・ノーマル・AO・金属・つや・発光・描画モード・描画する面 |
| そのほか | 色・テクスチャ・ノーマル・発光だけ |

**動作**

- 先に部位のプリセット(肌・顔・髪・服・金属・顔パーツ)を当て、その上に元の値を写します。元の影色や輪郭線が優先されます。
- MToon・UTS の影色は「影の色そのもの」なので、地の色で割って、GalaxyToon の「地の色に掛ける色」に直します。
- 中身の無い小さなテクスチャ(VRoid が入れる 8×8 のマットキャップや平らなノーマル)と、強さ 0 のノーマルマップは写しません。使っていない機能の負荷を増やさないためです。
- 部位の名前は、VRoid の名前(`Face_00_SKIN`、`HairBack_00_HAIR`、`EyeWhite_00_EYE`、`Tops_01_CLOTH` など)にも合わせてあります。

**項目**

| 項目 | 説明 |
|---|---|
| 元のマテリアルを書き換える | OFF(おすすめ): 複製を作って Renderer に差し替えます。元のマテリアルは残ります<br>ON: 元のマテリアルのシェーダーを変えます。VRM などから取り込んだ、書き換えられないマテリアルは複製になります |
| 保存先フォルダ | 複製の保存先。同じ名前のマテリアルがあれば上書きします(GUID を保つので、ほかからの参照は切れません) |
| Galaxy Toon Face を付ける | キャラのルートに `GalaxyToonFace` を付けます |
| 瞳と頬の位置を探す | [瞳の範囲を探す](#瞳の範囲を探す)・[頬の位置を探す](#頬の位置を探す) と同じ処理をします |
| 輪郭線のなめらか法線を焼く | [輪郭線用のなめらか法線を焼く](#輪郭線用のなめらか法線を焼く) と同じ処理をします。焼いたメッシュは保存先フォルダの `OutlineNormals/` に入ります |
| 髪の影を設定する | 髪に「髪の影を落とす」、顔と瞳に「髪の影を受ける」を当て、[髪の影を有効にする](#髪の影を有効にする) を実行します |

- 操作は Undo(Ctrl+Z)で戻せます。
- 写せないもの(MToon の影テクスチャがメインテクスチャと違う場合、画面基準の輪郭線の太さなど)は、Console にメモが出ます。
- VRM ファイルとして書き出すと、GalaxyToon のマテリアルは使えません(VRM の規格で使えるのは MToon などだけです)。移行は、Unity の中で使うキャラ向けです。

## 瞳の範囲を探す

顔メッシュから瞳の位置を自動で探し、顔マテリアルの「瞳1の範囲」「瞳2の範囲」に入れます。「瞳の効果を使う」も ON になります。

**使い方**

1. ヒエラルキーでキャラ(または顔の GameObject)を選びます。
2. **Tools > GalaxyToon > 瞳の範囲を探す (選択中のキャラ)** を実行します。
3. 結果が Console に出ます。

**探し方**

- 白目のサブメッシュの範囲の中に、まるごと収まる「メッシュの島」を瞳とみなします。
- まつ毛のような細い島は外れ、正面から見ていちばん大きい島が選ばれます。
- 瞳が別のサブメッシュ(瞳だけのメッシュなど)でも探せます。

**必要な条件**

- 顔(肌)と白目が、同じ SkinnedMeshRenderer の別サブメッシュであること
- 白目のマテリアル名に `Sclera` / `EyeWhite` / `白目` / `Eye` のどれかが入っていること
- 瞳のマテリアル名に `Iris` / `Pupil` / `瞳` が入っていると、そのサブメッシュが優先されます

## 頬の位置を探す

白目の少し下・外側にある、正面を向いた肌の頂点を頬とみなし、顔マテリアルの「頬の位置」と「頬染めの大きさ」に入れます。

**使い方**

1. キャラを選びます。
2. **Tools > GalaxyToon > 頬の位置を探す (選択中のキャラ)** を実行します。

**必要な条件**

- 白目(`EyeWhite` / `Sclera`)と肌(`Skin` / `Face`)が、同じ SkinnedMeshRenderer の別サブメッシュであること

## ノーマルマップを作る

テクスチャの明るさを高さとみなして、ノーマルマップを作ります。Read/Write が OFF のテクスチャや、圧縮済みのテクスチャでも使えます。

**使い方**

1. **Tools > GalaxyToon > ノーマルマップを作る (テクスチャから)** でウィンドウを開きます。
2. ヒエラルキーで Renderer を選ぶと、そのメインテクスチャが自動で入ります。テクスチャを直接入れてもかまいません。
3. 設定を調整して、作成します。

**項目**

| 項目 | 説明 |
|---|---|
| 対象の Renderer | 任意。選ぶと、マテリアルとメインテクスチャが自動で入ります |
| マテリアル | Renderer の何番目のマテリアルを使うか |
| 元のテクスチャ | 明るい所を高く、暗い所を低いとみなします |
| 強さ | 凹凸の深さ |
| なめらかさ (px) | 先にぼかして、ノイズを消します |
| 細かい模様だけ | 影や塗り分けの大きな明暗を除き、布目・毛束・しわなどの細かい凹凸だけを拾います。キャラにはふつう ON にします |
| 大きな明暗とみなす大きさ (px) | 「細かい模様だけ」で除く明暗の大きさ |
| 反転 | 暗い所を高くします |
| 最大サイズ | 作るテクスチャの最大サイズ(256〜4096) |
| 保存先 | PNG の保存先 |
| マテリアルに反映 | 作ったら、マテリアルの「立体感 (ノーマルマップ)」に入れます |
| 反映時の立体感の強さ | 反映するときの「立体感の強さ」 |

## 輪郭線用のなめらか法線を焼く

同じ位置にある頂点の法線を平均した「なめらか法線」を、メッシュの UV8(TEXCOORD7)に焼きます。輪郭線がこの法線で押し出されるので、角で線が割れたり途切れたりしなくなります。

**使い方**

1. プレハブ(Project ウィンドウ)か、シーン上のオブジェクトを選びます。複数選べます。
2. **Tools > GalaxyToon > 輪郭線用のなめらか法線を焼く (選択中のプレハブ・オブジェクト)** を実行します。

**動作**

- `GalaxyShader/Toon` を使う Renderer のメッシュだけを焼きます。
- 元のメッシュ(FBX)は書き換えません。複製を `OutlineNormals/` フォルダ(プレハブと同じ場所。シーン上のオブジェクトなら `Assets/OutlineNormals/`)に保存し、Renderer に差し替えます。
- 頂点の並びは変えないので、ブレンドシェイプや頂点番号を使う機能はそのまま動きます。
- もう一度実行すると、同じファイルに焼き直します。

## SDF 影マップを作る

メッシュの形から SDF 影マップを作ります。光が正面から横へ回っていくとき、各ピクセルが何度で影に入るかを、R(光が右から)と G(光が左から)に書き込みます。

**使い方**

1. **Tools > GalaxyToon > SDF 影マップを作る** でウィンドウを開きます。
2. ヒエラルキーで顔の Renderer を選びます。
3. 種類を選び、**作成** を押します。

**項目**

| 項目 | 説明 |
|---|---|
| 対象の Renderer | SkinnedMeshRenderer か MeshRenderer。スキンメッシュは基本の姿勢(バインドポーズ)で作ります |
| マテリアル(サブメッシュ) | このマテリアルが使う部分だけで作ります |
| 種類 | **顔**: 頭の楕円体へ強く寄せ、鼻・口の影を消します<br>**体**: なめらかにした体の形のまま<br>**髪**: 頭の球へ寄せ、毛束ごとの細かい影を消します |
| 解像度 | 256〜2048 |
| キャラの正面 | 顔が向いている向き。「自動」はキャラのいちばん上の親の正面(+Z)を使い、FBX の軸の違いも合わせます |
| なめらかさ | 法線をなめらかにする強さ。上げるほど影の形が大きく単純になります |
| 頭の形へ寄せる | 顔・髪で、頭を楕円体とみなした形へ寄せる強さ。1 で完全に楕円体の影 |
| 保存先 | PNG の保存先 |
| マテリアルに反映 | 作ったら、マテリアルの「SDF 顔影」に入れて ON にします |

> 「体」は T ポーズで焼く前提です。腕・脚のように曲がる部位に使うと、関節で影がガタガタになります。胴体のような固いメッシュにだけ使ってください。

## ランプのひな形を作る

影とハイライトのランプ画像のひな形を、2枚まとめて作ります。部位ごとに4段(上から 肌 / 髪 / 服 / 金属)のグラデーションが入っています。

**使い方**

1. Project ウィンドウで、保存先のフォルダを選びます(選ばなければ `Assets/`)。
2. **Tools > GalaxyToon > ランプのひな形を作る (影・ハイライト、部位4段)** を実行します。
3. 作った画像を、マテリアルの「影のランプ」「ハイライトのランプ」に入れます。
4. マテリアルの「ランプの段数」を **4** にします。
5. 「ランプの段」か「部位IDマップ」で、使う段を選びます。

**作られる画像**

| 画像 | 内容 |
|---|---|
| `GalaxyToon_ShadowRamp_4Rows.png` | 影。左=いちばん暗い、右=光 |
| `GalaxyToon_SpecularRamp_4Rows.png` | ハイライト。左=光の外側、右=光の中心。黒=光らない |

段の境目でにじまないよう、ミップマップなし・圧縮なしで読み込まれます。画像編集ソフトで描き直して使えます。

## 前髪を透過する

選んだキャラのルートに **GalaxyToonSeeThroughBangs** を付けます。再生中、前髪の毛先がグラデーションで半透明になり、眉や目が前髪越しに見えます。

**使い方**

1. ヒエラルキーでキャラ(子のオブジェクトでも可)を選びます。
2. **Tools > GalaxyToon > 前髪を透過する (選択中のキャラ)** を実行します。
3. 透ける範囲は、付いたコンポーネントで調整します。

**必要な条件**

- Humanoid の Animator があること
- 髪のマテリアルが `GalaxyShader/Toon` で、名前に `hair` が入っていること

## 髪の影を有効にする

プロジェクトで使っている URP Renderer(Graphics の既定と、各品質レベルのパイプラインアセットの Renderer)に **GalaxyHairShadowFeature** を足します。すでに入っている Renderer には何もしません。結果は Console に出ます。

髪の影を出すには、このほかにキャラのルートの **GalaxyToonFace** と、髪・顔のプリセットが要ります([顔・瞳・髪](shader-face-hair.md#髪の影))。

## 全マテリアルの機能を整理

プロジェクト内の `GalaxyShader/Toon` の全マテリアルについて、値に合わせてキーワード(機能の ON/OFF)を設定し直します。

- 値が効いていない機能のキーワードが外れるので、計算が減ります。
- ビルドに入るシェーダーの組み合わせも減り、ビルドが小さく、読み込みが速くなります。
- スクリプトでマテリアルの値を変えたあとや、古いマテリアルを取り込んだあとに実行してください。
- 終わると、[使っている機能の一覧](#使っている機能の一覧) も Console に出ます。

## 使っている機能の一覧

プロジェクト内の `GalaxyShader/Toon` の全マテリアルを調べ、Console に次の内容を出します。

- 機能の組み合わせの種類の数(= ビルドに入るシェーダーの組み合わせの数)
- 組み合わせごとのマテリアルの数と、マテリアルの例
- 機能ごとの使用数

組み合わせの数が多すぎるときは、似たマテリアルの設定をそろえると、ビルドが小さくなります。

## シェーダー OFF

GalaxyToon の全マテリアルを、同じテクスチャのまま、URP 標準の Lit と同じ計算で描きます。輪郭線も消えます。トゥーンにした効果を見比べるための機能です。

- ショートカットは **Ctrl+Shift+T** です。もう一度押すと元に戻ります。
- マテリアルの値は変わりません。
- Inspector の上部のボタンからも切り替えられます。

## 負荷を測る

再生中のシーンで、機能を1つずつ切りながら、GPU と CPU のフレーム時間を測ります。

**使い方**

1. シーンを再生します。
2. **Tools > GalaxyToon > 負荷を測る (再生中のシーン)** を実行します。
3. 測り終わると、結果が Console に出ます。切った機能は全部元に戻ります。

**測る内容**

| 段階 | 内容 |
|---|---|
| 全部あり(基準) | 何も切らない状態 |
| 被写界深度なし / ブルームなし | ポストエフェクトを切る |
| (Renderer Feature 名) なし | URP の Renderer Feature を1つずつ切る |
| 輪郭線なし | GalaxyToon の輪郭線を切る |
| ライトの影なし | ライトの影を切る |
| キャラなし | `GalaxyToonFace` を持つキャラを非表示にする |
| 描画解像度 0.5 | URP の描画解像度を半分にする |

各段階で、1秒慣らしてから3秒測ります。SetPass Calls、Draw Calls、三角形の数も記録します。

> ポストエフェクトの段階は、シーンの Volume で被写界深度・ブルームが有効なときだけ測ります。
