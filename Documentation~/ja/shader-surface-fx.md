# シェーダー: 濡れ・汗・液体・汚れ

[ドキュメント目次](README.md)

`GalaxyShader/Toon` の見出し **濡れ・汗・液体・汚れ** の説明です。テクスチャを用意しなくても、汗の粒・液体の筋・泡・雨の波紋・汚れ・傷をシェーダーの中で作ります。

## 共通

| 項目 | 説明 |
|---|---|
| 濡れ・汗・液体を使う | ON にすると、この見出しの機能が全部有効になります。OFF のマテリアルは、`GalaxyToonEffects` で量を変えても変わりません |
| 出る場所 | どこに効果を出すかのマスク。R=濡れ、G=汗、B=液体、A=泡(白=出る) |
| 粒・筋の盛り上がり | 汗の粒・液体の筋・泡・波紋の凹凸の強さ。ハイライトが粒の形に光ります |

各効果は「量」と「受ける強さ」の組になっています。

- **量**: どれだけ出すか。キャラ全体で `GalaxyToonEffects` から動かせます。
- **受ける強さ**: このマテリアルがどれだけ受けるか。例えば、服は汗を受けないように 0 にします。

## 濡れ

| 項目 | 説明 |
|---|---|
| 濡れ | 量(0〜1) |
| 濡れを受ける強さ | このマテリアルが受ける強さ |
| 濡れると濃く | 水を吸うと、テクスチャ自身の色で掛けて濃くなります(0.5=二乗、1=三乗)。布や革は色が深くなります |
| 濡れのつや | 濡れた面のつやの強さ |
| 染み込み | コンクリート・石・布などで、濡れた所がまだらに濃くなります。濡れが増えるほど染みが広がり、最後は全面が濃くなります |
| 濡れて縮む | 布や毛が水を吸ってふくらみが減り、体に沿います。濡れ 1 のとき、法線の内側へ寄せる量(cm)。ふわふわのしっぽなら 4〜6 |

- 汗をかくと、肌全体もうっすら濡れてつやが出ます。
- 髪の濡れ表現は、[異方性ハイライト](shader-highlight.md#異方性ハイライト髪の天使の輪) の「濡れ髪」と組み合わせます。

## 汗

UV をマス目に分け、マスごとにランダムな位置・大きさの汗の粒を置きます。

| 項目 | 説明 |
|---|---|
| 汗 | 量(0〜1)。増やすほど粒が増えます |
| 汗を受ける強さ | 肌=1、服=0 |
| 汗の粒の細かさ | 粒のマスの数 |
| 汗の粒の大きさ | 粒の大きさ |
| 汗が流れる速さ | 0 で止まったまま。上げると、粒がゆっくり下へ流れます |

## 液体

体に沿って垂れた筋を作ります。

| 項目 | 説明 |
|---|---|
| 液体 | 量(0〜1)。1 でも、およそ半分までしか覆いません |
| 液体を受ける強さ | このマテリアルが受ける強さ |
| 液体の色 | 色。A が不透明さです |
| 液体の筋の細かさ | 筋の細かさ |
| 液体が垂れる速さ | 筋が流れる速さ |
| 液体のつや | つやの強さ |
| 液体の粘り | 0=さらさら、1=ネバネバ。粘るほど流れが遅く、丸い塊になり、中央が盛り上がった厚い膜になります |
| 液体が流れる向き | 流れる向き(物体空間の XYZ)。既定は下向きです。口の中なら舌先へ向けます |

## 泡

大・中・小の3層の泡を重ね、大きな泡のすき間を小さな泡が埋めます。UV に貼るので、体を動かしても泡は滑りません。

| 項目 | 説明 |
|---|---|
| 泡 | 量(0〜1)。泡はかたまりで付き、量が多いほど範囲が広がります |
| 泡を受ける強さ | このマテリアルが受ける強さ |
| 泡の色 | 色。A が濃さです |
| 泡の細かさ | UV 1 あたりの大きい泡の数 |
| 泡の大きさ | マスに対する泡の半径 |
| 泡が滑り落ちる速さ | ワールドの下向きに滑り落ちる速さ |
| 泡が割れる速さ | 1秒あたり。泡は寿命の終わりに縮んで割れ、別の泡が生まれます |
| 泡どうしのつながり | 近い泡どうしがつながる量 |

## 雨

ワールド座標で作るので、地面・屋根・壁・キャラのどこに使っても、同じ雨になります。

| 項目 | 説明 |
|---|---|
| 雨 | 量(0〜1) |
| 雨を受ける強さ | 屋根の下などは 0 にします |
| 雨の波紋 | 上を向いた面の波紋。地面・水たまり=1、服・髪・肌=0 |
| 雨のしずくが流れる量 | 立った面を流れ落ちるしずくの量。服・髪は少なめにします |
| 表面で雨が跳ねる強さ | 体の表面で跳ねるしぶきの強さ。`GalaxyToonEffects` の `rainSplashMaterial` を設定したときに使います |
| 雨の波紋・しずくの細かさ | 1m あたりの細かさ |
| 雨の速さ | 波紋の広がりと、しずくの流れの速さ |

雨が当たる面は、全体もうっすら濡れます。

## 汚れ・傷

| 項目 | 説明 |
|---|---|
| 汚れ・すす | 量(0〜1)。物体に張り付いたしみで、量が増えるとしみが広がってつながります。つやも消えます |
| 汚れ・傷を受ける強さ | このマテリアルが受ける強さ |
| 汚れの色 | 色。A が濃さです |
| 汚れの細かさ | 1m あたりの細かさ |
| 傷 | 量(0〜1)。細いひっかき傷が、ランダムな向き・長さで入ります |
| 傷の色 | 下地が見えた色。A が濃さです |
| 傷の細かさ | UV 1 あたりの細かさ |

## ゲーム中に量を変える

キャラのルートに **GalaxyToonEffects** を付けると、キャラ全体の量をまとめて変えられます。

```csharp
using GalaxyToon;

var fx = GetComponent<GalaxyToonEffects>();
fx.wet = 1f;      // 濡れ
fx.sweat = 0.7f;  // 汗
fx.liquid = 0.5f; // 液体
fx.foam = 0.5f;   // 泡
fx.rain = 1f;     // 雨
fx.dirt = 0.3f;   // 汚れ
fx.scratch = 0.2f;// 傷
fx.blush = 0.8f;  // 頬染め
```

- 量はマテリアルごとの「受ける強さ」と「出る場所」マスクで、部位ごとに効き方が変わります。
- 雨に打たれている間に濡れていく速さや、乾く速さもコンポーネントで設定できます。
