# プリセット一覧

[ドキュメント目次](README.md) / [Inspector の使い方](inspector.md)

Inspector の **プリセット** にあるボタンの一覧です。押すと、その部位・素材に合った値がまとめて入ります。

- テクスチャとメインカラーは変わりません。
- 描画モードは、半透明や切り抜きが前提のプリセット(涙・しずく、宝石、レース、ガラスなど)でだけ変わります。
- 押したあとに値を調整してかまいません。

---

## キャラ

部位の基本設定です。キャラのマテリアルは、まずここから選びます。

| プリセット | 内容 |
|---|---|
| 肌 | やわらかい1段の影(赤み)、弱いリム、細い輪郭線 |
| 顔 | 肌と同じ色で、顔の細かい影を消します(顔の陰影を平らに 0.8)。キャラに `GalaxyToonFace` を付けると、首の向きに追従します |
| 髪 | くっきりした2段の影、天使の輪のようなハイライト、細いリム、輪郭線 |
| 服 | 布らしい2段の影、細いリム、輪郭線。光沢はありません |
| 金属 | 強いハイライトとリム、濃い影。マットキャップに金属の球テクスチャを入れると、さらに金属らしくなります |
| 顔パーツ | 目・歯・舌・まつ毛など。影をほとんど付けず、輪郭線もありません |

## キャラの仕上げ

ほかの値を変えずに、機能を足します。

| プリセット | 使うマテリアル | 内容 |
|---|---|---|
| 髪の影を落とす | 髪 | この髪の形で、顔・瞳に前髪の影を落とします |
| 髪の影を受ける | 顔・瞳 | 髪の影が光の向きに合わせて落ちます(長さ 1.2cm) |
| 瞳 くっきり | 顔・瞳 | 瞳に奥行きと、大小2つのハイライトを付けます |
| 瞳 うるうる | 顔・瞳 | 涙ぐんだ瞳。ハイライトが小刻みに揺れ、瞳の下で水面の光が波打ちます |
| 瞳 きらめき | 顔・瞳 | 瞳の中で十字の星がまたたきます |
| 照れ顔 | 顔 | 頬がほんのり赤くなり、斜めの照れ線が入ります |
| ラメ | 衣装・小物 | 細かい鏡の粒が、光と視線の向きでキラキラまたたきます。出る場所は「ラメの出る所」マスクで決めます |
| 近づくと透ける | 髪・体 | カメラが 30cm より近いと網目で透け、10cm で消えます。寄りのカメラでめり込んだとき、中が見えなくなります |
| アニメ塗り | 全部 | 日本のアニメ調。影色を地の色から自動で作り、境界をくっきりさせ、輪郭線を画面上で同じ太さにします。肌は「影色の色相ずらし」を + にすると、赤みのある影になります |

- 「髪の影」を使うには、URP に `GalaxyHairShadowFeature` を追加する必要があります(**Tools > GalaxyToon > 髪の影を有効にする** で追加できます)。
- 瞳の範囲は **Tools > GalaxyToon > 瞳の範囲を探す**、頬の位置は **頬の位置を探す** で自動設定できます。

## 肌・服の質感

影やハイライトなど今の値はそのままに、質感だけを上書きします。

| プリセット | 内容 |
|---|---|
| 肌 汗 | 肌に汗の粒を出します(汗 0.7) |
| 肌 濡れ | 肌全体が濡れて色が濃くなり、てかります(濡れ 1) |
| 肌 液体(白) | 白い液体が、垂れた筋になって流れます(液体 0.6)。色は「液体の色」で変えられます |
| 肌 雨 | 雨に打たれた肌。水は染み込まず、水滴が玉になって流れ落ちます |
| 涙・しずく | 涙・水滴・雨粒の透明な水。半透明・両面で、鋭いハイライトと縁の光が付き、影は受けません。`GalaxyTears` や糸のマテリアルに使います |
| 宝石(屈折) | 宝石・クリスタル・厚いガラス。半透明で後ろの景色がゆがみ、虹色ににじみ、細かい面がきらめきます |
| 服 ソフト | 柔らかい布(綿・ニット)。ぼけた影で、つやはありません |
| 服 ラテックス | ラテックス・エナメル。くっきりした影、小さく鋭いハイライト、強い縁のてかりと映り込み |
| 服 皮製品 | 革(ジャケット・ブーツ・ベルト)。やや広いハイライトと弱い映り込み、しっかりした影 |
| 服 濡れ | 雨や水で濡れた服。色が濃く沈み、ふくらみが減って体に沿います(縮み 1.5cm) |
| 髪 濡れ | 雨に濡れた髪。毛が束になり(濡れ髪)、ふくらみが縮み(1cm)、少しずつ色が濃くなります |
| 革 濡れ | 雨に濡れた革。少し水を吸って色が深くなり、布より早く表面につやが出ます。縮みません |

量は `GalaxyToonEffects` の `wet` / `sweat` / `liquid` / `rain` で、ゲーム中に動かせます。

## 追加(今の設定に足す)

ほかの値は変えず、効果だけを足します。重ねて押せます(汗 + ウェット など)。

| プリセット | 内容 |
|---|---|
| 汗 | 汗の粒を足します(汗 0.7、流れません) |
| 流れる汗 | 汗の粒が、ゆっくり下へ流れます(汗 0.7、流れる速さ 0.3) |
| 液体 | 白い液体の筋を足します(液体 0.6) |
| 流れる液体 | 液体の筋が下へ垂れていきます(液体 0.6、垂れる速さ 0.5) |
| ネバネバ | とろっと粘る半透明の液を足します(粘り 0.9、ゆっくり垂れます)。糸を引かせるには `GalaxyStickyStrings` を使います |
| ウェット | 全体を濡らします(濡れ 1) |
| 泡 | 白い泡を足します。ゆっくり滑り落ち、泡どうしがつながり、割れて小さくなります(泡 0.7) |
| 雨 | 上を向いた面に波紋が広がり、立った面をしずくが流れ落ち、全体が濡れます |
| 雨 染み込み | コンクリート・石・布が水を吸い、まだらに色が濃くなります。つやはあまり出ません |
| 汚れ・すす | すす汚れ。しみが体に張り付き、つやが消えます(汚れ 0.5) |
| 泥汚れ | 茶色い泥はね(汚れ 0.45) |
| 傷 | 細いひっかき傷。下地の明るい色が線になって見え、少しへこみます(傷 0.5) |
| 転送(消える) | 足元から光る線が上がり、線の通った所が消えます。ディゾルブの量を 0→1 に動かします |
| 転送(現れる) | 光る線とともに現れます。ディゾルブの量を 1→0 に動かします |

転送は、`GalaxyTeleport` を付けると自動で動きます(服の入れ替えもできます)。

## 背景

建物・小物向けです。シーンのメインライト・環境光・追加ライト・ほかの物の影を受けます。輪郭線は付けません。

| プリセット | 内容 |
|---|---|
| 木目 | ニス・ワックスを塗った木(床・家具・楽器)。木目に沿った筋状のつやと、弱い映り込み |
| 木材 | 塗っていない木(角材・板・木箱)。つやも映り込みもなく、影はやわらかめ |
| 金属 | むき出しの金属(配管・手すり・機械)。金属 1・つや 0.7 |
| 塗装金属 | 塗装した金属(扉・ロッカー・壁)。金属 0・つや 0.5 |
| コンクリート | コンクリート・石・床。つやなし、ぼけた影。UV が無い場合はトライプラナーを ON にします |
| プラスチック | 樹脂の小物。金属 0・つや 0.65、白いハイライト |
| ペットボトル | 薄い透明な樹脂。半透明・両面で、鋭いハイライトと白く光る縁。中身の色はメインカラー(A)で決めます |
| 透過プラスチック | ライトのカバーなどの色付き樹脂。半透明で、強い映り込みと縁の光。点灯は「発光色」で表します |
| ガラス | 窓・レンズ。半透明で、つや 0.95 の強い映り込み |
| ダイヤモンド | 宝石・クリスタル。鏡のような映り込み、鋭いハイライト、強い縁の光 |
| 水 | 水面・水たまり。半透明で後ろがゆがみ、鏡のような映り込み。上を向いた面に雨の波紋がゆっくり広がります(止めるなら「雨」を 0) |
| レース | レース・網。テクスチャの A で穴を抜き(切り抜き)、両面、つやなし |
| 紙 | 紙・段ボール。つやも映り込みもなく、影はやわらかく薄め |
| 発光パネル | 照明・モニター・看板。影を薄くし、発光色を入れます。ライトマップを焼くと、周りも照らします |
| マグマ | 溶岩・溶けた金属。赤橙の発光がゆっくり脈打ちます。発光の形はテクスチャの明るい所で決まります |
| 建物の壁 | 外壁・内装のつや消し塗装。つや 0.2、やわらかい影 |

## リセット

|---|---|
| 基本以外リセット | テクスチャ・メインカラー・立体感・描画モード・描画する面はそのまま、ほかの項目を全部初期値に戻します |
