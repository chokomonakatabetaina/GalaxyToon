# GalaxyToon Documentation (English)

[日本語](../ja/README.md) | English

This documentation explains GalaxyToon screen by screen and feature by feature. For installation and basic usage, see the [README](../../README.en.md) at the top of the repository.

Setting names are written as they appear when the Inspector language is set to **English**. Menu items and tool windows are shown in Japanese, so they are written as the Japanese name followed by an English translation, e.g. **瞳の範囲を探す** (Find Iris Area).
